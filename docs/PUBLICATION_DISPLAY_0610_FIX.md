# 0.6.10 研究成果展示与发布修复

日期：2026-09-24。实际源码：`auto-research-init-v5`。本补丁保留已有专家会话持久化父地址导航与返回主会话修复。

## 已完成

- 成果概览、节点详情和材料列表使用同一成果卡片。历史成果显示节点/项目短标题、普通字重四行预览，展开读取完整发布说明，支持 Markdown 和原文切换。不会把分页预览作为全文。
- 说明中的标题降为正文层级，超过 120 字符的标题按段落显示。正文 14px、1.7 行距，长路径换行，表格在局部滚动；来源与核验缺口折叠。概览不再重复列出最新成果摘要。
- 明确指定的附件作为主报告；否则只有唯一 Markdown 附件可直接阅读，多个报告或没有报告时显示材料入口。路径不从摘要猜测。
- 知识列表使用简短纯文本，详情读取完整 Markdown。阅读弹窗支持 Escape 关闭并恢复按钮焦点和页面位置。
- `research_publish` 增加可选 `display`：`title`、`overview`、`sections[{heading,items}]`、`primary_item_id`。保留必填 `summary` 和旧调用。工具说明及角色提示要求按目标语言区分已有结果、待验证假设、限制，无需新增模型调用。
- 展示内容以 `publication-display/v1` 保存为本次成果的 `__research_display` 专用 item，复用 JSON 存储。项目概览及发布分页提供可选投影，普通附件列表隐藏专用项。损坏/未知版本展示信息回退历史卡片，不跨成果引用展示信息。未增加表或迁移历史数据。
- 新增只读 `reference.chunk` RPC，超长完整说明可分块读取并正确拼接 UTF-8。

## 生效方式与兼容性

已同步到源码和当前 web profile 的已安装插件。前端刷新后生效。当前 DSH 研究进程未被重启，未向活跃研究会话注入指令、处理审批或改写研究账本。新的工具参数、角色提示及分块读取 RPC 随下一次正常服务加载和新建研究会话生效。

现有服务已能完整读取真实 P-001 说明。若某条历史说明超过旧服务的单次读取上限，而旧服务尚未加载新增分块 RPC，界面会明确报告全文不可读取；不会把预览冒充全文。待研究结束后正常加载新服务即可使用分块读取。
