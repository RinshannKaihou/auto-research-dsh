# 认识层规格（0.6.7–0.6.9）

本目录只保留认识层的语义规格，描述 0.6.9 中已实现的行为。源码与测试引用这三份文件：

| 文件 | 内容 |
|---|---|
| `A0_RULES.md` | 规则 R1–R45：依据视图、变更事件、受影响集合、风险与处置、发布核查、冻结引用、来源、候选提示、字段检查 |
| `A0_COUNTEREXAMPLES.md` | 反例 CE-1 到 CE-27 的预期输出；`tests/test_067_regressions.py` 逐行断言 |
| `A0_SCHEMA.md` | 存储、schema 7–9 迁移与接口 |

规格正文里有一些来源标注，如 S 编号、审阅编号、E1。它们指向已移出仓库的过程文件，只说明规则当初从何而来，不作为后续开发的依据。`src/auto_research/hints.py` 注释里提到的 `docs/067/E1/e1_query.py` 也已移出。规格里写的字段检查参考实现路径 `docs/history/067_b_contract/field_check_reference.py`，现在对应 `tests/field_check_reference.py`，测试读的是这份。

0.6.7 及更早版本的过程记录与证据已于 2026-09-23 移出仓库，包括计划、简报、报告、复核、事故记录、E1/E2/E3 实验和验收证据。E3 经用户裁定没有决策价值，不构成证据。
