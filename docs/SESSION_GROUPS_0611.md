# 0.6.11 项目会话分组

日期：2026-09-24。此改动继续纳入 0.6.11。

## 展示

项目会话不再平铺所有专家。默认显示主会话与节点会话，展开节点后显示下属专家的任务编号、任务标题和状态；专家自己的详情可再次展开，查看完整任务标题、会话 ID 和“打开会话”入口。节点标题显示已加载专家数量及运行/待处理计数，原生审批入口保持可见。“节点内部协作”清单也默认折叠，避免再次平铺全部专家。

优先使用持久化父会话，区分同节点重试后的不同执行会话。历史页可借用当前页之外、已加载的父会话作为归属上下文；缺失父地址时仅在节点核心唯一时展示在该节点下，导航仍由持久记录解析，绝不猜测原生父地址。归属不明的记录单独折叠收纳。计数表示已加载范围，保留分页“加载更多”。

## 兼容与验证

新服务的会话页以单次批量查询补齐专家任务编号、标题、用途类型、状态和父地址，标题限制为 240 字符，不返回任务提示词或完整结果。旧服务展开节点时按需读取任务标题、缓存结果，每批最多 4 个详情请求。界面不额外调用模型，不写研究账本。

- Node 回归 109 项通过；Python 相关回归 27 项通过。
- 覆盖相同节点的不同父会话、父记录不在当前页、历史归属上下文、项目级专家、孤立记录、旧服务按需补标题、正确跳转及只读分页。
- 客户端构建检查通过；新包全部文件与源码、已安装插件逐字节校验。
