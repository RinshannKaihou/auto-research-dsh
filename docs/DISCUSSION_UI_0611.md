## 实现

- 研究过程时间线每个节点新增“讨论进展”；图/时间线共用的节点详情新增“围绕此节点讨论”及“更多 → 新建另一场讨论”。默认复用，fresh 显式新建，防止重复点击。
- 直接跳转原生讨论会话；使用原生 Workspace/Session API 登记讨论自己的 cwd、绑定同一 session，并为默认标题设置节点、角色及短编号。保留已有自定义标题。
- 页头与输入区显示当前节点及角色，区分主会话、节点执行、讨论、专家、接手。页头还显示项目与会话短编号。提供返回主会话，专家可返回父会话。
- 命令结果返回 sessionId 时可直接打开目标会话。
- 已结束专家经父/主会话读取身份信息，不把父会话状态误当成专家状态。
- 节点详情固定面板受原生滚动视口约束，防止滚动后按钮落在屏幕上方。
